# CocodeAI

CocodeAI 是酷码工作室（Cocode Studio）开发的智能桌面助手，帮助你更高效地完成 AI 辅助工作。支持 macOS、Windows 和 Linux。

> 基于开源项目 OpenWork 改造而来，针对中文用户深度定制。

**下载 CocodeAI**：https://cocodeai.com/download

---

## 快速安装

### 系统要求

- macOS 13+, Windows 10+, 或 Linux
- Node.js 24+

### 开发模式

```bash
pnpm install
pnpm --filter @cocodeai/desktop dev:electron
```

---

## 核心功能

- **智能助手**：多模型支持，灵活切换 AI 提供商
- **工作区管理**：本地和远程工作区，团队协作
- **Skills 技能系统**：可复用的工作流模板
- **浏览器自动化**：内置浏览器面板
- **语音模式**：实时语音交互
- **跨会话记忆**：持久化上下文
